Privacy policy

Last updated: 2026-10-06

Morning Brief Ultra Pro Max Tier is a personal, self-hosted program. It has no servers run by its developer and no user accounts.

What it accesses

With the Google account owner's permission, it reads Google Calendar events, Gmail message headers and short previews, and Google Tasks, using read-only permissions.

What happens to the data

  • It is processed only on the computer the owner installed the program on.
  • It is summarized by an AI model that also runs on that computer. It is not sent to a cloud AI service.
  • It is not sent to the developer, sold, shared, or used for advertising.
  • The login token is stored in a private file on the owner's computer. The owner can delete it, or revoke access at any time at myaccount.google.com/permissions.

Google API Services User Data Policy

Morning Brief Ultra Pro Max Tier's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
