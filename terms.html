2. What the software is

The software is a personal, self-hosted program that runs on your own computer. Once a day it reads your Google Calendar, Gmail and Google Tasks, and optionally Canvas LMS, weather and news feeds, and writes a single summary page for you.

  • It is read-only. It requests only read-only Google permissions and contains no code that writes to Google, Gmail or Canvas.
  • It is not a hosted service. There are no user accounts or subscriptions, and the developer runs no servers.
  • Part of each brief is written by AI. A small language model on your computer writes the short summary at the top, and that text can be wrong.

How the software handles data is described in the privacy policy.
